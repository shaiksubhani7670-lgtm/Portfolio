## 🛠️ Tech Stack

- **Framework:** React 18, TypeScript, Vite
- **Styling:** Custom Light-Theme Editorial Design System (Vanilla CSS tokens)
- **Icons:** Lucide React
- **Deployment:** Vercel & GitHub

---

## 📌 Features

- **Editorial Light-Theme Design:** Clean typography, generous whitespace, charcoal text, soft blue accents, and 2D geometric accents.
- **Hero & Profile:** Natural portrait crop and status indicators.
- **Featured Project — FindIt Campus:** Interactive 4-step 2D visual product mockup demonstrating the lost-and-found matching workflow.
- **Verified Skills:** Categorized badge pills for Python, JavaScript, HTML5, CSS3, Flask, and SQLite.
- **Academic Journey:** Timeline for Geethanjali Institute of Science and Technology.
- **Quick Contact:** Direct mailto triggers and one-click clipboard copy with instant toast confirmation.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shaiksubhani7670-lgtm/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
